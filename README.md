# Descripcion del Proyecto 
El equipo ZERION propone diseñar un prototipo de aplicacion de escritorio desarollado en c# y conectado a una base de datos MySQL para apoyar la gestion de informacion de fundacion UNIFRANZ en COCHABAMBA la solucion busaca organisar los registros de beneficiarios personas en situacion de calle y animales las donacionas economicas y materiales y las ayudas estrategas. La necesidad identifica se relaciona con el uso actual de hojas de calculo en la nube y con la posibilidad de duplicacion y formacion.  
# Tecnologias que se usaran
se usaran GitBash, Aiven, Visual Code Studio, MySQL, Trello y GitHub
